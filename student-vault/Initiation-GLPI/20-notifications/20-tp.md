# TP 20 — Claire reçoit la confirmation

> Chapitre associé : [[20-cours-fil-rouge]]

## Mission

Créer un ticket de Claire dans **Le Fournil Doré** et retrouver sa notification dans la boîte **Claire Rousseau** de smtp4dev. Utiliser [le schéma interactif](schema-notifications-interactif.html) pour suivre les étapes.

## A — Préparer l'envoi

1. Dans smtp4dev, créer **Settings → Mailboxes → Claire Rousseau**, destinataire `claire@fournil-dore.fr`.
2. Dans GLPI, avec votre compte Super-Admin, activer les notifications par mail et régler le SMTP sur `192.168.3.254:25`, sans authentification.
3. Définir `glpi@fournil-dore.fr` comme expéditeur et `support@fournil-dore.fr` comme adresse de réponse.
4. Envoyer un mail de test à l'administrateur et le retrouver dans smtp4dev.

## B — Vérifier la notification

1. Dans **Configuration → Notifications → Notifications → New Ticket**, vérifier l'état **Actif**, le modèle **Tickets** et le destinataire **Demandeur**.
2. Vérifier l'e-mail `claire@fournil-dore.fr` dans la fiche de Claire.
3. Avec Claire, créer un nouveau ticket `Test notification pour Claire` dans la racine.

## C — Suivre le message

Dans **Administration → File d'attente des notifications**, repérer le message s'il attend encore l'envoi. Dans **Configuration → Actions automatiques → queuednotification**, vérifier le mode **CLI** et les journaux. Dans smtp4dev, ouvrir la boîte **Claire Rousseau** et contrôler le destinataire, le numéro, le titre et le lien du ticket.

> [!NOTE] Deux sens de circulation
> `mailgate` lit les mails **entrants** de Support en IMAP. `queuednotification` expédie les notifications **sortantes** vers smtp4dev en SMTP.
