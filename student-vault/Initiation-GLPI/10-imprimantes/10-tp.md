# 10 — Les imprimantes dans GLPI · TP

> Chapitre associé : [[10-cours]]

---

## Atelier — Référencer l'imprimante du Fournil Doré

> **Contexte** : avec votre compte Super-Admin, référencer l'imprimante située à Nantes et suivre ses cartouches. Son entité reste **Le Fournil Doré**.

---

### Étape 1 — Créer l'imprimante

Connectez-vous avec `admin.fournil / a12345!`, sélectionnez **Le Fournil Doré** sans « Arborescence », puis créez l'imprimante :

`Parc` → `Imprimantes` → **+ Ajouter**

| Champ | Valeur |
|-------|--------|
| Nom | `IMP-NAN-OPENSPACE-01` |
| Entité | Le Fournil Doré |
| Statut | En inventaire |
| Lieu | `Nantes > Open space` |
| Type | Laser multifonction |
| Fabricant | Brother |
| Modèle | MFC-L8900CDW |
| Numéro de série | `BRO-2024-001` |
| Numéro d'inventaire | `IMP-001` |
| Technicien responsable | `admin.fournil`, si proposé |
| Utilisateur principal | *(aucun)* |

Cliquer sur **+ Ajouter**.

![[glpi11-10-imprimante-fournil.png]]

*L’imprimante du Fournil dans la liste GLPI 11.*

---

### Étape 2 — Créer les modèles de cartouches

La Brother MFC-L8900CDW accepte les toners TN-421 (4 couleurs), selon la [fiche Brother](https://store.brother.fr/appareils/laser/mfc/mfcl8900cdw). Créez les 2 modèles suivants :

`Parc` → `Cartouches` → **+ Ajouter**

**Cartouche 1 :**

| Champ | Valeur |
|-------|--------|
| Nom | `Brother TN-421BK (Noir)` |
| Référence | `TN-421BK` |
| Fabricant | Brother |
| Seuil d'alerte | `2` |
| Objectif de stock | `4` |

**Cartouche 2 :**

| Champ | Valeur |
|-------|--------|
| Nom | `Brother TN-421C (Cyan)` |
| Référence | `TN-421C` |
| Fabricant | Brother |
| Seuil d'alerte | `1` |
| Objectif de stock | `2` |

> Pour aller plus loin : créer également `TN-421M` (Magenta) et `TN-421Y` (Jaune) avec les mêmes paramètres que le Cyan.

---

### Étape 3 — Lier le modèle d'imprimante

Pour chaque modèle de cartouche créé → onglet **Modèles d'imprimantes** → sélectionner `MFC-L8900CDW` → **Ajouter**.

---

### Étape 4 — Alimenter le stock

Pour chaque modèle → onglet **Cartouches** → saisir la quantité → **Ajouter des cartouches** :

| Modèle | Quantité |
|--------|---------|
| Brother TN-421BK (Noir) | 3 |
| Brother TN-421C (Cyan) | 2 |

---

### Étape 5 — Installer les cartouches sur l'imprimante

Depuis `Parc` → `Imprimantes` → `IMP-NAN-OPENSPACE-01` → onglet **Cartouches**

| Modèle | Compte | Action |
|--------|--------|--------|
| Brother TN-421BK (Noir) | 1 | Cliquer **Installer** |
| Brother TN-421C (Cyan) | 1 | Cliquer **Installer** |

Vérifier que les 2 cartouches apparaissent bien dans la section **Cartouches en cours d'utilisation**.

---

### Étape 6 — Vérifier

Depuis `Parc` → `Imprimantes` → `IMP-NAN-OPENSPACE-01` :
- ✅ Les informations sont complètes (lieu, N° de série, N° d'inventaire)
- ✅ L'onglet **Cartouches** affiche 2 cartouches en cours d'utilisation

Depuis `Parc` → `Cartouches` :
- ✅ Les 2 modèles apparaissent dans la liste
- ✅ Le stock de chaque modèle a diminué d'une unité (installée sur l'imprimante)
