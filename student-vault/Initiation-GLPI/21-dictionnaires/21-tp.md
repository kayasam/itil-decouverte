# TP 21 — Uniformiser un éditeur

> Chapitre associé : [[21-cours]]

## Mission

Avec votre compte Super-Admin, normaliser les variantes de l'éditeur **Microsoft** dans les logiciels de **Le Fournil Doré**. Le nombre de logiciels dépend de vos inventaires ; il n'y a pas de total imposé.

## A — Observer les données

Dans **Parc → Logiciels**, chercher `Microsoft`. Relever les orthographes réellement présentes. Si aucune variante n'existe, créer une fiche de logiciel de démonstration dans la racine avec l'éditeur `Microsoft Corp.`, puis revenir au dictionnaire.

## B — Créer et tester la règle

1. **Administration → Dictionnaires → Logiciels → Ajouter**.
2. Nom : `Normaliser éditeur Microsoft` ; **Activé = Oui**.
3. Critère : **Éditeur contient Microsoft**.
4. Action : **Éditeur → Assigner → Microsoft Corporation**.
5. Ouvrir **Tester le moteur de règles** et essayer `Microsoft`, `Microsoft Corp.` et une valeur sans Microsoft.

Les deux premières valeurs doivent devenir **Microsoft Corporation** ; la dernière ne doit pas correspondre.

## C — Appliquer et vérifier

Après un test concluant, cliquer **Rejouer les règles du dictionnaire**. Retourner dans **Parc → Logiciels** et contrôler quelques fiches. La [[21-cours|méthode 2 CLI]] peut rejouer le dictionnaire si l'interface n'est pas utilisée pour cette dernière étape ; ne pas lancer les deux pour le même essai.
