# TP 19 — Le mail de Claire devient un ticket

> Chapitre associé : [[19-cours]]

> [!NOTE] Mission
> Claire écrit à `support@fournil-dore.fr`. smtp4dev reçoit le message, puis GLPI le collecte et crée un ticket dans **Le Fournil Doré**.

## A — Vérifier les deux machines

1. Sur Windows `192.168.3.254`, vérifier que smtp4dev fonctionne à `http://localhost:5000`.
2. Dans **Settings → Mailboxes**, vérifier la boîte **Support**, destinataire `support@fournil-dore.fr`.
3. Dans **Settings → Users**, vérifier le compte IMAP `support@fournil-dore.fr`, mot de passe pédagogique `a12345!`.
4. Dans GLPI, avec votre compte Super-Admin, vérifier le collecteur **Support Fournil Doré — smtp4dev** : serveur `192.168.3.254`, IMAP port `143`, sans TLS, actif.

## B — Envoyer le mail

Sur Windows, ouvrir un autre PowerShell et exécuter :

```powershell
Send-MailMessage `
  -From 'claire@fournil-dore.fr' `
  -To 'support@fournil-dore.fr' `
  -Subject 'Caisse : impossible de joindre le réseau' `
  -Body 'Bonjour, le poste de caisse ne charge plus les sites. Claire.' `
  -SmtpServer '192.168.3.254' `
  -Port 25
```

Le mail doit être visible dans la boîte **Support** de smtp4dev. `Send-MailMessage` peut afficher un avertissement de dépréciation ; vérifier la réception du mail.

## C — Collecter et vérifier

1. Dans **Configuration → Collecteurs**, ouvrir **Support Fournil Doré — smtp4dev** et cliquer **Récupérer les mails maintenant**.
2. Dans **Assistance → Tickets**, rechercher `Caisse : impossible de joindre le réseau`.
3. Vérifier **Demandeuse = Claire Rousseau**, **Entité = Le Fournil Doré**, **Source = E-Mail** et le corps du message.
4. Relancer la collecte sans nouveau mail : aucun second ticket identique ne doit apparaître.

Si GLPI refuse le message pour une entité, examiner **Mails non importés**, la règle d'affectation du collecteur vers **Le Fournil Doré** et l'habilitation de Claire sur la racine.
