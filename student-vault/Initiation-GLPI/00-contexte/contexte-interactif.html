Une entité, deux lieux

Les lieux Nantes et Rennes servent à localiser le matériel. Ils ne créent pas de sous-entités : tout le laboratoire reste dans l'entité racine Le Fournil Doré.

Le schéma est aussi disponible au format SVG dans les ressources de la formation.

Les intitulés du laboratoire

Dans GLPI, les intitulés sont des listes configurables. Choisissez une famille, puis retrouvez les noms utilisés dans les chapitres et TP.

Une catégorie ITIL classe un ticket ; un lieu situe un équipement. Dans les deux cas, l'entité reste Le Fournil Doré.

Le parcours GLPI → ITIL

L'initiation construit le laboratoire. La découverte ITIL réutilise les mêmes objets pour raisonner sur les services.

1

Construire GLPI

Serveur, utilisateurs, lieux, catégories, parc et messagerie.

2

Claire signale

Une panne de IMP-NAN-OPENSPACE-01, située à Nantes > Open space.

3

Étudier la cause

Incidents récurrents, problème, changement de pilote préparé et plan de repli.

4

Améliorer

SLA, relations entre équipements, mesure et amélioration continue.

Le changement de pilote reste prévu si aucun pilote approprié n'est disponible. Le laboratoire ne requiert ni domaine Active Directory ni GPO.
