# TP 05 — Préparer un changement de pilote

> Chapitre associé : [[05-cours]]. Le changement prolonge le problème `Pannes récurrentes — IMP-NAN-OPENSPACE-01` du TP 04. Vous utilisez votre Super-Admin, dans l'entité racine **Le Fournil Doré**.

## A — Évaluer le changement

L'hypothèse du TP 04 pointe vers le pilote d'impression du **poste de Claire**. Vous proposez de tester une version stable, puis de la conserver si l'impression fonctionne. Il s'agit d'un changement **normal** : l'intervention peut être planifiée, comporte un risque et doit avoir un retour arrière.

| Question | Votre réponse |
|---|---|
| Quel service risque d'être indisponible pendant le test ? |  |
| Qui valide l'intervention dans le scénario du Fournil Doré ? |  |
| Quel test prouve que la nouvelle version fonctionne ? |  |
| Comment revenir à la version précédente ? |  |

Le laboratoire ne contient pas de domaine Active Directory. **Aucune GPO n'est créée** dans ce TP ; le plan porte sur le poste Windows et l'imprimante déjà connus.

## B — Créer le changement dans GLPI

Dans **Assistance → Changements → Ajouter**, renseigner :

| Champ | Valeur |
|---|---|
| Titre | `Tester un pilote stable — IMP-NAN-OPENSPACE-01` |
| Description | Tester sur le poste de Claire une version stable du pilote Brother, après les incidents liés à l'imprimante de Nantes. |
| Demandeur / attribué à | Votre compte Super-Admin |
| Lieu | Nantes > Open space |
| Impact / urgence | Moyen / Faible |
| Entité | Le Fournil Doré |

Lier le changement au problème du TP 04 et à `IMP-NAN-OPENSPACE-01`.

## C — Rédiger les trois plans

**Plan de déploiement**

1. Relever la version actuelle du pilote et conserver son installateur.
2. Prévenir Claire d'une interruption courte de l'impression.
3. Installer la version stable choisie sur le poste Windows du laboratoire.
4. Imprimer une page de test, puis un document de travail avec Claire.
5. Noter la version et le résultat dans le changement.

**Plan de repli**

1. Si les tests échouent, désinstaller la nouvelle version.
2. Réinstaller la version précédente conservée.
3. Vérifier une page de test et informer Claire du résultat.

**Liste de vérification**

- [ ] Le poste voit `IMP-NAN-OPENSPACE-01`.
- [ ] La page de test sort correctement.
- [ ] Claire confirme le test d'un document de travail.
- [ ] La version du pilote et le résultat sont notés.

Saisir ces plans dans les sections **Analyse** et **Plans** de la fiche GLPI. Le changement peut être documenté sans modifier réellement le pilote si aucun paquet approprié n'est disponible sur le poste du laboratoire. Dans ce cas, garder la mise en œuvre au statut **prévue** et ne pas déclarer le changement appliqué.

## D — Suivre le statut

Faire évoluer le dossier selon les validations **réellement effectuées** : création, évaluation, validation et test. Passer à **Appliqué**, **Revue** puis **Clos** uniquement si la mise en œuvre et les vérifications ont été réalisées. Noter dans le changement ce qui a été fait et ce qui reste à faire.

## Contrôle

- [ ] Le changement est lié au problème du TP 04 et à l'imprimante.
- [ ] Les plans de déploiement, de repli et de test sont renseignés.
- [ ] Le statut décrit l'avancement réel.
- [ ] Aucun domaine ou GPO non présent dans le laboratoire n'est requis.
