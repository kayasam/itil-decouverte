# TP 03 — Qualifier et traiter un incident

> [!TIP] Ressource du TP
>
> - <a href="https://kayasam.github.io/itil-decouverte/telechargements/tp/03-tp.md" download>Télécharger ce TP en Markdown</a>

> Chapitre associé : [03-cours](/03-gestion-incidents/). Vous poursuivez **votre GLPI 11** de l'initiation, dans l'entité racine **Le Fournil Doré**. Connectez-vous avec votre compte Super-Admin ; Claire Rousseau reste la demandeuse.

## A — Qualifier avant de créer

Claire transmet cinq signalements. Pour chacun, noter s'il s'agit d'un **incident** ou d'une **demande de service**, puis proposer un impact et une urgence.

| #   | Signalement de Claire                                                             | Type | Impact | Urgence |
| --- | --------------------------------------------------------------------------------- | ---- | ------ | ------- |
| 1   | « `IMP-NAN-OPENSPACE-01` ne répond plus ; les bons de commande restent bloqués. » |      |        |         |
| 2   | « Je ne peux plus ouvrir GLPI depuis mon navigateur. »                            |      |        |         |
| 3   | « Je voudrais un deuxième écran pour mon poste. »                                 |      |        |         |
| 4   | « Le terminal de paiement refuse les cartes depuis trente minutes. »              |      |        |         |
| 5   | « Mon accès au dossier Comptabilité ne fonctionne plus. »                         |      |        |         |

Un incident correspond à un service interrompu ou dégradé ; une demande porte sur un besoin planifiable. **La priorité dépend de l'impact et de l'urgence**. Les cinq lignes servent à l'analyse ; seul le signalement **n° 1** est créé dans GLPI pour poursuivre le fil rouge.

## B — Créer l'incident de l'imprimante

Dans **Assistance → Tickets → Ajouter**, sélectionner **Le Fournil Doré** et saisir :

| Champ            | Valeur                                                                        |
| ---------------- | ----------------------------------------------------------------------------- |
| Type             | Incident                                                                      |
| Titre            | `Nouvelle panne de IMP-NAN-OPENSPACE-01`                                      |
| Demandeuse       | `claire.rousseau`                                                             |
| Catégorie        | Matériel > Imprimante                                                         |
| Lieu             | Nantes > Open space                                                           |
| Impact / Urgence | Moyen / Élevée                                                                |
| Attribué à       | Votre compte Super-Admin                                                      |
| Description      | Les bons de commande de Claire restent bloqués ; l'imprimante ne répond plus. |

Enregistrer. Dans la fiche du ticket, onglet **Éléments**, lier `IMP-NAN-OPENSPACE-01`. Vérifier la priorité calculée par GLPI et expliquer si elle correspond à votre analyse.

## C — Tracer le traitement

1. Passer le ticket à **En cours (Assigné)**.
2. Ajouter un suivi : `Contrôle de la file d'impression et de la connexion de l'imprimante. Redémarrage du service d'impression. Test demandé à Claire.`
3. Renseigner la solution : `Le service d'impression a été redémarré ; le bon de commande de test est sorti.`
4. Passer le ticket à **Résolu**. Garder le lien avec l'imprimante pour l'analyse du chapitre 04.

**Résolu** indique qu'une solution est proposée. **Clos** signifie que la clôture a eu lieu selon le processus retenu ; ne pas confondre ces statuts.

## Contrôle

- [ ] Le ticket est un incident de Claire dans **Le Fournil Doré**.
- [ ] `IMP-NAN-OPENSPACE-01` est liée au ticket.
- [ ] Un suivi et une solution sont visibles.
- [ ] Le ticket est résolu ; vous savez expliquer sa priorité.
